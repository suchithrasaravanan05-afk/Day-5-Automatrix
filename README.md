# Day 5: WiFi Connect

This project connects the ESP32 to Wokwi’s virtual WiFi network and prints its assigned IP address to the Serial Monitor.

## Hardware

- ESP32 DevKit v1

No additional components are required.

## WiFi Settings

- Network: `Wokwi-GUEST`
- Password: leave blank

## Wokwi Simulation

[Run the simulation](https://wokwi.com/projects/476331131578995713)

## How to use

1. Start the Wokwi simulation.
2. Open the Serial Monitor.
3. Wait for the ESP32 to connect.
4. Check the Serial Monitor for the assigned IP address.
